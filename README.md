# Familio — Семейный бюджет

Премиальный SaaS для ведения совместного семейного бюджета.

## 🚀 Быстрый старт
1. `git clone ...`
2. `cp .env.example .env` (настройте переменные)
3. `npm install`
4. `docker-compose up -d db` (или используйте свой PostgreSQL)
5. `npm run db:migrate && npm run db:seed`
6. `npm run dev`

## 📦 Production
`npm run build && npm start`
